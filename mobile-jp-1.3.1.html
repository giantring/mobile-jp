v1.3.1 · 휴대폰 안에서 바로 패치합니다. 인터넷 연결이 필요 없고 파일은 어디로도 전송되지 않습니다.

⛔ 최우선 경고 — 「삼총사 전설」 미션 진행 금지

X360 Mobile 에서는 신시가지의 「삼총사 전설」 미션(솔레아나의 시련)을 절대 진행하지 마세요. 시련을 불러올 때 게임이 튕기고 세이브가 손상되어 게임이 아예 켜지지 않을 수 있습니다.

  • 스토리 진행에 필요한 미션이 아닙니다. 신시가지의 로시가 미션을 제안하면 거절하세요.
  • 에뮬레이터 문제이며 한글패치와는 관계없습니다.

⚠ 주의 — 마을에서 수동 저장

에뮬레이터에서 마을에서 메뉴를 열어 직접 저장할 때 게임이 튕겼다는 사례가 있습니다. 튕기면 세이브가 손상될 수 있으니, 중요한 지점 전에는 세이브 폴더(534507D6)를 다른 곳에 복사해 두세요. 에뮬레이터 데이터 폴더에서 534507D6 을 검색하면 찾을 수 있습니다.

  • 튕긴 뒤 게임이 켜지지 않으면, 세이브 폴더 이름을 바꾸고(예: 534507D6_bak) 실행해 보세요. 켜지면 세이브 손상이니 백업으로 되돌리세요.

1게임 ISO 패치

원본 ISO는 그대로 두고, 한글이 들어간 _KO.iso 를 새로 만듭니다. 휴대폰에 게임 용량만큼 빈 공간이 더 있어야 합니다.

2언어 설정은 그대로

영어·일본어 어느 쪽으로 실행해도 한글로 나옵니다. X360 Mobile 설정은 바꾸지 않아도 됩니다.

타이틀 ID: 534507D6 · 영어 모드에서는 온라인(네트워크) 메뉴 문구만 영어로 남습니다.

3게임 실행

  1. 만든 _KO.iso 를 X360 Mobile 게임 폴더로 옮깁니다. (다운로드 폴더에 저장됩니다)
  2. 목록을 새로 고치고 _KO 쪽 게임을 실행합니다. 원본 ISO는 지우거나 다른 폴더로 옮겨도 됩니다.
  3. 타이틀 화면과 메뉴가 한글로 나오면 성공입니다.
압축 푼 폴더(default.xex)로 쓰는 경우

게임 폴더 안 xenon/archives 에서 text.arc, cache.arc, event.arc 세 개를 함께 고르세요. 패치된 파일 세 개를 받아 같은 자리에 덮어쓰면 됩니다. 덮어쓰기 전에 원본을 다른 곳에 복사해 두세요.

ISO 저장이 실패할 때 (PC 에서 패치)

휴대폰 저장 공간이 부족하거나 저장이 멈추면, ISO 를 PC 로 옮겨 PC 패키지의 설치 프로그램으로 패치한 뒤 휴대폰으로 다시 옮기세요. 같은 번역이 들어갑니다.

  1. ISO 를 PC 로 옮깁니다.
  2. PC 패키지(같은 번역: 일어 기반 / 영어 기반)의 설치 프로그램을 실행하고, ISO 파일을 창에 끌어다 놓은 뒤 1(설치)을 고릅니다. ISO 가 그 자리에서 패치됩니다.
  3. 패치된 ISO 만 휴대폰의 X360 Mobile 게임 폴더로 옮깁니다. 옆에 생긴 .korean_undo 는 PC 에 두세요 (되돌릴 때 필요).
